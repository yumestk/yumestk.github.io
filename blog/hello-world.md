# Hello World — Starting My Blog

Every developer eventually starts a blog. This is mine.

## Why I'm Writing

I've been coding for a while now, and I've noticed something: the best way to solidify understanding is to explain it to someone else. Writing forces clarity. If you can't explain it simply, you don't understand it well enough.

So this blog is partly for you, but mostly for me — a way to process ideas, document solutions, and leave breadcrumbs for my future self.

## What to Expect

I'll be writing about:

- **Frontend development** — Vue, TypeScript, CSS tricks, performance
- **Backend** — Java, Spring Boot, API design
- **Tools & workflow** — things that make development faster and more enjoyable
- **Projects** — deep dives into things I'm building

## The Stack

This blog itself is built with [VitePress](https://vitepress.dev/), a static site generator powered by Vue 3 and Vite. It's fast, flexible, and lets me write in Markdown — which is exactly what I want.

The design is inspired by the UI of Persona 3 Reload — dark, geometric, with that signature blue accent. Building it was a fun exercise in CSS and component design.
